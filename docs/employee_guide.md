# 「うみやまAI」 のご案内

OWNDAYS のみなさまへ

海山の AI 分身 「うみやまAI」 を社内で活用できるようにしました。
日々の業務や判断で 「ちょっとした資料レビュー、壁打ち相手が欲しい」 という場面で気軽に使ってください。

---

## 「うみやまAI」 って何

- 海山の過去の発言・判断・話し方・趣向を学習した AI
- LINE WORKS で 1:1 でも、グループでも会話できる
- 会話内容が記憶されるためパーソナライズされる
- 売上・各種業務・経営判断・相談について 海山っぽい視点で返答
- ただの問い合わせ bot ではなく、クローンとして使う想定

今後、音声やアバターによる音声での壁打ち、会議の参加機能も追加する予定です。

---

## 使い方

### 1. 1:1 で相談する (= LINE WORKS DM)

LINE WORKS の上部ウィンドウ 「連絡先を検索」 から 「うみやまAI」 を追加してください。

```
社員: 売上が低迷している。どこから手をつけるべき?
うみやまAI: なるほど。まずは低迷している理由が客数なのか単価なのか...
```

### 2. グループに招待する

会議のグループに 「うみやまAI」 を追加。
`@うみやまAI` で mention した時だけ反応します (= 普通の会話には割り込まない)。

### 3. 資料を添付する

PDF / Google Docs / Sheets / Slides の URL や添付で投げれば、中身を踏まえて返答します。

Google Drive の場合: `bot-account@example.co.jp` に閲覧権限を付与してから URL を投げてください。

## 質問例

### 業務系

- 「SV 選挙の資料をレビューして」
- 「この新店候補、海山の判断軸でいうとどこに引っかかる?」
- 「店舗運営で一番大事なことは? 単価か客数?」

### 数字系

- 「昨日の全社売上、客数の状況を教えて」
- 「2026 年 5 月時点の総店舗数」

### 判断軸系

- 「採用面接で 海山が必ず聞くことは」
- 「投資判断の優先順位について。どれくらいの期待値」
- 「失敗が許される領域とそうじゃない領域」

### 雑談系

- 「最近やる気が出ません。どうしたら良いですか?」
- 「最近読んだ本でおすすめは?」

## うまく使うコツ

| よくある誤解 | 実態 |
|---|---|
| 全部正確に答えてくれる | AI なので間違えます。重要判断の最終確認は人で |
| Google みたいに何でも知ってる | OWNDAYS 業務 + 海山の発言した範囲 が中心 |
| 業務を代行してくれる | 今は代行はしない。「自分で考えるための壁打ち相手」 |
| 機密情報を教えてくれる | 人事評価、M&A 等の機密情報は返答できません |

## プライバシー — 何が記録されるか

社員から信頼してもらうため、ここは率直に書きます。

### 記録されるもの

- 会話内容 (= 質問 + AI 応答)
- 質問のタイミング (= 日時)
- LINE WORKS user_id (= システム識別子)

### 海山の Dashboard 上は完全匿名化

海山が品質改善のため Dashboard で会話を確認することがありますが、
個別社員は完全匿名化されて表示されます:

```
田中 太郎 → 「社員 A」
鈴木 花子 → 「社員 B」
営業本部チーム → 「グループ A」
```

実名 / 実所属が海山の Dashboard に直接表示されることはありません。

### 記録されないもの (= 自動 filter)

- プライバシーに関する情報
- 電話番号 / 住所 / その他個人特定情報
- 第三者 (= group 外社員 / 取引先) の悪口

## 困ったとき

| 状況 | アクション |
|---|---|
| 応答が間違っている / 完全におかしい | 「違う、正しくは ○○」 と返信 → 修正登録 + 学習 |
| Drive 開けないと言われる | 共有先に `bot-account@example.co.jp` を追加 |
| 応答が無い時 | まだ不安定なので時々動かなくなります |

---

## 重要

- 重要な業務判断は 必ず人と確認
- 困ったら上司に相談
- AI を信用しすぎないこと
- ベータ版のため、徐々に品質改善が進みます
