# 「うみやまAI」 利用にあたって

社員のみなさまへ、

「うみやまAI」 (= 海山社長の AI 分身) を社内 LINE WORKS で公開するにあたり、
プライバシーに関する取り扱いを以下の通り明示します。安心して活用ください。

## ✅ 保存されるもの

「うみやまAI」 との対話は、応答品質の継続改善のため以下の情報が記録されます:

- 会話内容 (= 質問 + AI 応答)
- 質問のタイミング (= 日時)
- LINE WORKS user_id (= システム内部識別子)
- 表示名 / 所属 (= LINE WORKS から取得可能な範囲)

## 🔒 海山の Dashboard 上の表示

社長が品質確認するための Review Dashboard (= /admin/review) では、
**個別社員は完全匿名化** されて表示されます:

- 「田中 太郎」 → 「社員 A」
- 「鈴木 花子」 → 「社員 B」
- group チャット → 「グループ A」「グループ B」

**実名 / 実所属が社長の Dashboard に直接表示されることはありません**。

## 🎯 何のために記録されるか

- 応答品質の継続改善 (= 月次品質 review、誤回答 検出)
- 海山社長の判断軸・話法の精度向上 (= AI を 海山社長らしく育てる)
- 進行中の話題の継承 (= 「あの件」「前回の話」が自然に通る)

## 🚫 利用しないもの

以下の情報は 「うみやまAI」 が**記録 / 利用しないように設計**されています:

- 個人の健康 / 家族の private な事情
- 性的な内容
- 個人を特定できる電話番号 / 住所
- 第三者 (= group 外社員 / 取引先) の悪口

これらは自動 filter で会話履歴 / memory から排除されます。

## 📁 backend (= raw data) の取り扱い

- 実名・実 user_id は backend (= サーバー内 file system) には保存されます
  - 理由: 各社員に対する個別最適化応答に必要 (= 「田中さん」が「あの件」と言った時の文脈解決)
- 海山社長個人 LINE での `/clone-memory <prefix>` コマンド経由で参照可
  - これは 緊急時の品質確認用 (= 通常は Dashboard 経由匿名化表示のみ)
- 第三者には開示されません
- 退職 / 利用停止希望時には対象 user 全 data を削除可能 (= `/clone-forget <user_id>`)

## 💡 利用 tips

- 質問は自由に投げてください (= business 文脈・個人キャリア相談・市場動向相談 等)
- 「これ録音されるの?」 を意識する必要はないですが、**極端に sensitive な個人事情** は LINE WORKS 経由じゃなく 1:1 面談で
- group での mention (= @うみやまAI) で集団議論にも投入可
- 応答が誤りなら 「違う」「正しくは ○○」 と返信 → 学習されます

## ❓ 質問 / 申し入れ

- 利用方法質問: グループ「うみやまAI 質問」 (← 別途設置予定)
- プライバシー懸念 / data 削除 申請: 海山社長 LINE 直接
