## 【Long Version】(社内ポータル詳細ページ / 後追い読みたい人用、~2000 字)

```
社員のみなさんへ

「うみやまAI (v1)」を、本日 2026-05-X 付で正式公開します。

▼ うみやまAI とは

僕 (海山) の AI 分身。OWNDAYS の業務知識 (売上 / 戦略 / 組織 / VMV)、
判断軸、応答スタイルを学習した AI です。

LINE Works で 1:1 DM できます。役職問わず、全社員 200 名が使えます。

▼ なぜ正式公開するか

僕は 200 人の社員一人ひとりと毎日 1:1 で話したい。実際は無理。
うみやまAI が「**海山に聞きたかったあれ**」を、海山がいない時にも答えてくれる。

200 人それぞれが OWNDAYS の判断軸・戦略・トーンで同じ理解で動ければ、
ベクトル合わせの時間が減って、各人が本業 + 創意工夫 にエネルギーを向けられる。

これが OWNDAYS の「Voice & Do」と「Customer Obsession」を組織として強める道だと考えています。

▼ なぜ「v1」なのか

うみやまAI は version 概念で進化していきます:

- **v1 (今回正式公開)**: 「聞ける AI」 — 質問応答、考え方アライン
- **v2 (時期未定、将来)**: 「頼める AI」 — タスク実行、業務伴走

v1 の reality を見てから v2 をやるか決めます。
v1 で十分なら v2 やらないかもしれない (= overengineering 回避)。

▼ v1 で出来ること

【業務データ即答】
・全店 / エリア / 国 / 業態 / 店舗別の売上 (今日、昨日、過去 3 年)
・AM / SV / 都道府県別の集計
・前年同月比、客単価、客数、TSA、KPI 系
・期間集計 (GW、年末年始、四半期等)

【会社の理解】
・OWNDAYS の VMV (10 Values 全文)
・組織図、執行役員、AM / SV / 店長
・戦略 (FY26 結果、FY27 AOP、新店開発方針)
・規定、文化、判断基準

【相談】
・「海山ならどう見るか」の視点出し
・キャリア相談、悩み相談
・1on1 前の整理、店舗運営の壁打ち
・新店候補の評価

【ドキュメント・URL】
・PDF / Excel / Word / 画像 (OCR) 添付の解析
・メッセージ内 URL の自動取得

▼ v1 で出来ないこと (= v2 で予定)

・メール / 議事録 / 提案書の作成
・スケジュール調整、招待状送信
・Drive / Slack / メールへの書き込み・送信
・タスク実行型のリクエスト (「これやって」「これ送って」)

→ いまは ChatGPT / Claude / 各社員自身がやる範囲です。

▼ 永続的に AI に任せない領域

・個別人事評価、処遇、解雇判断
・未公開 M&A、重大経営判断
・取引先 / 顧客への直接対応
・海山個人名での SNS / メディア発信

これらは AI に任せず、責任者が判断します。

▼ 使い方

1. LINE Works で「うみやまAI」を友達追加 (検索: うみやまAI)
2. 初回 welcome メッセージが届く、それ読んだら質問開始
3. 自然な日本語で書く。短くても長くてもいい。
4. 添付したい資料があれば一緒に送る (PDF / Excel / 画像 OK)
5. 応答が違ってたら「違う」「正しくは…」で直接返信

▼ プライバシー

【記録されるもの】
- 質問と応答 (= 履歴)
- ユーザ ID と表示名
- 個別メモリー (= 役職・所属・話題・スタイル好み)

【記録されないもの (= AI の prompt で明示禁止)】
- 健康の深刻な悩み
- 家族の極めて私的な事情
- 第三者の悪口・評価
- 性的内容
- 電話番号 / カード番号 / PII

【海山が見られるもの】
- やりとりの履歴 (= 学習サイクルのため)
- 修正希望
- 月次利用統計

【履歴削除】
海山に LINE Works で DM すれば即削除します。

▼ ベータからの改善点 (2026-04 → 2026-05)

- 応答モデル: GPT-5.4-mini → Claude Opus 4.8 (深い文脈理解)
- 個別メモリー: なし → 各社員ごとに memory 蓄積
- Sleep-time agent: 会話一区切り後に memory 再整理 (30 秒 idle)
- 売上履歴: 今日のみ → 3 年分の日次 / 月次 / 店舗別
- 議事録参照: なし → Plaud / Recall の議事録を参照可
- 添付ファイル対応: なし → PDF / Excel / 画像 (100 MB まで)
- URL 取り込み: なし → メッセージ内 URL を自動 fetch
- 修正フィードバック: ボタン → 直接返信「違う」「正しくは…」で自動記録
- 夜間自動チェック: なし → regression test + hallucination 検出 (03:30 / 03:45 daily)

▼ お願い

【1. 違ったら「違う」で教えて】

応答が事実と違ったり、トーンが違和感あったら、遠慮なく「違う」「正しくは…」で
直接返信してください。自動で記録され、僕が翌日 15:00 にレビューして wiki を修正します。
これが AI 改善の中心ループです。

【2. 大事な判断は自分で】

AI は参考意見です。法的・人事的・経営的に重要な判断は、必ず人間が責任を持って下してください。
AI が「いいよ」と言ったから、を理由にした判断は認めません。

【3. 機密の取り扱い】

うみやまAI とのやりとりを社外で共有しないでください。
特に「海山がこう言ってた」を社外で引用するのは、内容が AI 経由でも避けてください。

▼ 詳細

- 使い方ガイド: [URL] (詳細)
- FAQ: [URL] (よくある質問)
- 戦略 / Phase 整理: [URL] (なぜ v1 / v2 なのか)

▼ 質問・要望

僕に直接 LINE Works DM か、うみやまAI に「こういう機能欲しい」と言うと
記録されます。月次でレビューします。

▼ 最後に

これは僕の個人プロジェクトとして 2026-04 から始め、Claude (Anthropic の AI agent)
と一緒に組み上げました。コードの大半は AI が書き、僕は判断軸と方向性を提示してきました。

2026 年の AI 技術スタックがあったから 50 時間で形になりました。これを 200 人の
日常に置くことで、OWNDAYS の組織知化を一段進めたい。

楽しんで使ってください。

— 海山丈司
代表取締役 CEO
```
