# うみやまAI (v1) FAQ

★ 2026-05-21 正式公開版

USAGE_GUIDE.md に書ききれない「よくある質問」と「困った時の対応」をまとめてる。

## 基本的な疑問

### Q. うみやまAI と ChatGPT / Claude の違いは?

| | ChatGPT / Claude | うみやまAI (v1) |
|---|---|---|
| 一般知識 | ◎ | △ (OWNDAYS 中心) |
| OWNDAYS 業務知識 | ✗ | ◎ (社内データ全部入り) |
| 海山の判断軸 | ✗ | ◎ (本人の考え方を学習) |
| トーン | フォーマル / 一般的 | 海山の砕けたトーン |
| 売上数字 / 組織情報 | ✗ | ◎ |
| 文書作成・翻訳・コード | ◎ | ✗ (v2 で予定) |

→ **使い分け推奨**:
- 「海山ならどう見るか」「OWNDAYS の数字」 → うみやまAI
- 「翻訳して」「議事録 draft」「コード書いて」 → ChatGPT / Claude

### Q. 友達追加するとどうなる?

最初に **welcome メッセージ** が届く (= 何ができる / できない、修正の出し方、プライバシー)。
それを読んだら、普通に質問・相談を始めて OK。

### Q. 誰でも使える?

OWNDAYS 全社員、LINE Works アカウントがあれば誰でも。役職問わず。

### Q. 業務時間外に使ってもいい?

OK。AI なので 24h 365 日応答する。
ただし、業務時間外の相談を海山本人がレビューする時間は限定的、急ぎなら明示してほしい。

## v1 で出来ること / 出来ないこと

### Q. メール / 議事録 / 提案書を作ってほしい

→ **v1 では対応しない**。v2 (= AI agent 機能、時期未定) で対応予定。
今は ChatGPT / Claude を使ってください。

### Q. うみやまAI に予定を入れてほしい / 招待状を送ってほしい

→ **v1 では対応しない**。「予定を確認する」「招待状を送る」は v2 領域。

### Q. 添付ファイルを読んで応答できる?

→ **対応してる**。PDF / Word / Excel / 画像 (OCR) を添付して質問可。
1 ファイル最大 100 MB。

### Q. メッセージに URL を貼ったら?

→ **自動取得して内容に基づき応答する**。例:
```
「この記事の評価どう思います? https://example.com/article」
→ URL の中身読んで応答
```

### Q. 数字が知りたいんですが…

→ **得意領域**。例:
- 全店 / エリア / 国 / 業態 / 店舗別 売上 (今日 / 昨日 / 過去 3 年)
- AM / SV / 都道府県別の集計
- ゴールデンウィーク / 年末年始等の期間集計
- 前年同月比 / 前期比 / 客単価 / 客数
- TSA / KPI 系

### Q. 業績以外の質問もしていい?

→ **歓迎**。
- OWNDAYS の戦略・VMV・組織構造・規定
- キャリア相談・悩み相談
- 海山個人の趣味・嗜好・読書・音楽 (オープンに話す方針)
- 仕事の進め方・判断軸の聞き取り

### Q. ハルシネーション (= AI の作り話) は起きる?

→ **可能性ある**。ただし以下の対策が動いてる:
- 毎晩 03:45 に自動 fact verifier が走って矛盾検出
- 売上数字は wiki から直接引いてるので比較的安全
- 「違う」「正しくは」で訂正すると記録 → 海山が翌日 wiki 修正

→ **疑わしい数字は別ルートで確認**してほしい (= POS / 営業管理 / 直接確認)。

## 修正・フィードバック

### Q. 応答が違ってたらどうする?

普通に **直接返信** で OK。以下のキーワードで書き始めると自動で修正記録される:

- 「違う」「ちがう」「それ違う」
- 「正しくは…」「事実は…」
- 「間違ってる」「事実誤認」
- 「もう少し具体的に…」(= 補足扱い)

→ 翌日 15:00 に海山がレビュー → wiki 更新。

### Q. 修正が反映されたか分かる?

→ **直接の通知は無い** (= 多数の修正が来るため)。次回同じ質問で応答が改善されてれば反映完了。

### Q. 「キャンセル」したい時は?

→ 修正中の場合: 「キャンセル」と返信
→ 履歴を削除したい: 海山に直接 LINE Works DM

### Q. プライバシーが心配なんだけど

→ 詳細は USAGE_GUIDE.md の §5 参照。
要点:
- 健康深刻 / 家族プライベート / 第三者悪口 / 性的内容 / PII は **保存しない**
- 海山がやりとり閲覧可能 (= 学習サイクルのため)
- 履歴削除は海山に DM で即対応

## トラブルシューティング

### Q. 「ごめん、応答生成中にエラーが出ました」 が返ってきた

→ **内部障害** (= LLM API / Chroma / コンテナ等)。1-2 分待って再送信。
継続するなら海山に LINE Works で「うみやまAI 落ちてる?」と DM、海山が docker 確認します。

### Q. 30 秒以上応答が来ない

→ 重い処理中 (= 添付ファイル解析 / 過去 1 年分集計 等) の可能性。1 分待って状況変わらなければ報告。

### Q. 数字が明らかに間違ってる

→ **「違う、正しくは X です」** と返信。自動記録 → 海山レビュー → 修正。

### Q. トーンが違和感ある (硬すぎる / 砕けすぎ)

→ 「もう少し砕けて」「もう少し丁寧に」で調整リクエスト可。次の応答から調整される。

### Q. 同じ質問なのに前と違う答えが返ってきた

→ AI なので **少し揺れる**。気になるレベルなら「違う」で訂正、海山がレビュー。

## v2 についての疑問

### Q. v2 はいつリリースされる?

→ **時期未定**。海山判断 (2026-05-21): 「v1 の reality を見てから決める」。
v1 が安定運用できて、社員ニーズが見えてから着手する。**早くて 2027 年、もしくは v1 で十分なら v2 やらない**。

### Q. v2 では何ができる?

→ **タスク実行・業務伴走** が主追加。例:
- 議事録 draft 自動生成
- 売上レポート自動作成
- スケジュール調整補助
- データ集計 + 文書化
- 業務 workflow 自動化

技術詳細は `docs/strategy/PHASES.md` 参照。

### Q. v1 と v2 の境目はどこで決まる?

| | v1 (= 聞ける AI) | v2 (= 頼める AI) |
|---|---|---|
| 動詞 | 「答える」「示す」 | 「やる」「作る」「送る」 |
| 出力 | テキスト | テキスト + 実行アクション |
| 責任 | 参考意見、最終判断は社員 | 実行責任を伴う、要承認 |
| リスク | 誤回答による誤判断 | 誤実行による業務影響 |

### Q. v2 で「自分の代わりにメール送って」もできる?

→ できるけど **段階開放**。役職や信頼性に応じてツール許可を段階的に開ける。
かつ、外部送信前に **「これでいい?」と確認** する設計が前提 (= 暴走防止)。

## 海山に直接連絡したい時

| | 連絡手段 |
|---|---|
| うみやまAI の根本疑問 | 海山に直接 LINE Works DM |
| バグ・障害報告 (緊急) | 海山に LINE (個人) |
| 機密に関わる懸念 | 海山に LINE Works DM、必要なら対面 |
| 「これ欲しい」機能リクエスト | うみやまAI に「こういう機能欲しい」と話す (= 記録される) or 海山に DM |
| プライバシー懸念 | 海山に直接 |
