# うみやまAI (v1) 使い方ガイド

★ 2026-05-21 正式公開版 (β → v1.0)

LINE Works で **「うみやまAI」を友達追加するだけ** で 1:1 DM 開始。
全 OWNDAYS 社員が利用可能、登録不要、いつでも気軽に。

★ **これは v1 (= version 1)**。質問応答 + 海山の考え方アラインに特化。
将来 v2 で「タスク実行・業務伴走」が追加予定 (時期は v1 の reality 次第)。

---

## 1. うみやまAI って何

**海山の AI 分身**。海山の判断軸・価値観・知識を学習した AI が、24 時間
社員からの DM に応答する。

ただし「**海山の代わりに作業する補助者**」ではない (= v1 の段階では)。

### v1 でできること
- ✅ 「海山ならどう判断するか」の **視点出し**
- ✅ 業務データ (店舗売上 / 業績 / 組織 / VMV) の **即答**
- ✅ 悩み相談 / キャリア相談の **壁打ち相手**

### v1 でやらないこと (= v2 で予定)
- ❌ 資料作成 / 議事録 / メール代行 → v2 領域、いまは ChatGPT 等で
- ❌ Drive / Slack / メール への書き込み・送信 → v2 領域
- ❌ 自動で会議招集・予定設定 → v2 領域
- ❌ タスク実行 (「これやって」型) → v2 領域

### 永続的にやらないこと
- ❌ 個別人事評価・処遇決定 → 海山本人に直接
- ❌ 未公開案件・機密情報の判断 → 当事者間で
- ❌ 取引先 / 顧客と直接やりとり → 担当者経由で

「v1 でできないこと」と「永続的にやらないこと」を混同しない。前者は将来できるようになる、後者はずっと AI に任せない領域。

## 2. こんな時に使うと役立つ

### 「海山ならどう見るか」を聞きたい時

```
「店長の評価で迷ってるんですけど、売上は伸びてないけど
スタッフから慕われてるタイプ、海山さんならどう見ます?」

→ 海山の判断軸 (長期育成 / 数字以外の指標 / ROI 2 年 等) で応答
```

### 業務データを即答してほしい時

```
「サンプル駅前店の今日の売上は?」
「○○AMの担当 SV 一覧」
「ゴールデンウィークの売上は?」
「FY27 AOP の達成率」

→ wiki 経由で即答 (~5-10 秒)
```

### 仕事・人生の悩みの壁打ち

```
「30 代のキャリアで迷ってます」
「明日会社行きたくないです」
「同僚と方針が合わなくて疲れる」

→ 海山視点で 1 つの観点を出して、考える余白を残す応答
```

### OWNDAYS の戦略・文化を確認

```
「OWNDAYS の 10 Values を全部教えて」
「OWNDAYS の Vision って何でしたっけ」
「ブランド戦略本部って何する部署?」

→ wiki から正確に応答 (= 公開済 VMV / 組織図ベース)
```

## 3. 上手な使い方のコツ

### コツ 1: 質問は具体的に

| ❌ ぼんやり | ✅ 具体的 |
|---|---|
| 「うちって調子いいんですか?」 | 「FY26 の連結業績、特にアジア圏どうですか?」 |
| 「店長になりたいです」 | 「今 SV やってます、店長への道筋について海山視点で意見ください」 |
| 「人間関係つらい」 | 「上司との 1on1 で意見が通らない、どう向き合えばいい?」 |

具体的な方が、海山らしい鋭い応答が返る。

### コツ 2: 深掘りは追加質問で

最初の応答が浅く感じても、続けて聞けば徐々に深まる。

```
1. 「店長育成について教えて」
   → 一般論で返ってくる

2. 「具体的に売上低い店長を育成するときの順序は?」
   → より具体的に

3. 「数字以外で見るポイント 3 つ教えて」
   → 海山らしい視点が出る
```

### コツ 3: AI の限界を知る

- **専門領域 (医療・法律・税務・心理深刻ケース)** は AI の答えだけで判断しない、専門家相談を勧める
- **未公開 M&A・取引先機密・人事評価詳細** は答えない設計
- **数字は wiki にある範囲で正確**、無い数字は「まだ流し込めてない、今後拡充予定」と正直に返す (推測で数字は作らない)
- **間違えることもある**、大事な判断は自分の責任で

## 4. 応答が違ってたら教えてください

うみやまAI は **学習中**。間違いを直接返信で教えると海山がレビューして
wiki に反映する → 全社員に賢くなる。

### 修正の出し方 (どれでも OK)

```
「違う」「ちがう」  → 自動で訂正として記録
「正しくは…」     → 同上
「事実と違います」  → 同上
「もう少し具体的にいうと…」 → 補足として記録
```

→ 自動で「修正希望キュー」に入る → 海山が翌日チェック → wiki 更新

### こんな時も連絡してほしい

- 「これは個人情報なのでうみやまAI に話さないで」と感じた相手から
- 「この応答は会社の戦略を漏らしすぎてる」と気付いた時
- 「明らかにハルシネーション (作り話) してる」と分かった時

→ 海山に直接 LINE Works DM、または「違う」で記録

## 5. プライバシー

### 記録されること

- あなたと うみやまAI のやりとり (= 履歴として保存)
- ユーザ ID と表示名
- メモリー (= 役職・所属・進行中の話題・スタイル好み)

### 海山が見られること

- やりとりの履歴 (= 海山もレビューして学習サイクルに使う)
- 修正希望
- 利用統計 (= 月次でどう使われてるか)

### 記録されないこと

- 健康の深刻な悩み (= プロンプトで明示的に保存禁止)
- 家族の極めて私的な事情
- 第三者の悪口・評価
- 性的内容
- 電話番号 / カード番号 / 個人を特定する PII (= 自動除去)

### 履歴の削除

「海山さん、私の履歴消してください」と LINE Works で海山に DM すれば、即削除。

## 6. よくある場面別の使い方

### 朝の業績確認

```
あなた: 昨日の全店売上どうでした?
AI: 昨日の全店売上は 12,345,678 円、客数 1,000 名、客単価 12,346 円。
    平日にしてはやや低め、明日以降のリカバー次第。
```

### 1on1 前の準備

```
あなた: 部下との 1on1 で何を話せばいいか迷ってます
AI: 1on1 の目的次第。評価面談なら過去 3 ヶ月の事実を 3 つ。
    キャリア面談なら相手の wanted を聞き出すのが先。
    どっちの 1on1?
```

### 月末の戦略確認

```
あなた: 今月の AOP 達成見通しは?
AI: FY27 5 月 AOP は X 億、月末予測 Y 億 (達成率 Z%)。
    関東Aと九州A が好調、関西A はやや遅れ。海山的に
    関西A の梅田・心斎橋の動きを見たい時期。
```

### 悩み相談

```
あなた: 同僚と方針が合わなくて疲れる
AI: 合わない方針が「数字の見方」か「価値観」か「人柄」かで動き方が変わる。
    どれが一番大きい?
```

## 7. 制約と注意

### 応答の遅さ

- 平均: 6-12 秒 (smart モデル = Claude Opus 4.8 を使ってる)
- 重い処理 (= 添付ファイル解析、過去 1 年分データ集計) は 30 秒-1 分

### 同時アクセス

- 多人数が同時に聞いても OK、内部で並列処理
- ただし時間帯 (= 朝 9 時前後 / 月末 / 業績発表後) は応答遅くなる場合あり

### 添付ファイル

- PDF / Excel / Word / 画像 (OCR) を添付して質問可
- 1 ファイル最大 100 MB
- 添付内容を見て応答する

### URL 取り込み

- メッセージに URL を貼ると、自動で内容取得して応答する
- 例: 「この記事どう思います? https://...」

## 8. トラブルシューティング

| 症状 | 原因 | 対応 |
|---|---|---|
| 「申し訳ありません、少し時間を置いて…」が返ってくる | LLM 障害 or 内部エラー | 数分待って再送信 |
| 30 秒以上応答ない | 重い処理中 or 障害 | 1 分待って状況変わらなければ報告 |
| 「データが無い」と返される | wiki に該当 raw が無い | 期間や対象を変えて聞き直す |
| 数字が明らかに違う | 集計タイミング差 / バグ | 「違う」で訂正、海山がレビュー |
| トーンが違和感ある | スタイルパラメータ調整中 | 「もう少し砕けて」「もう少し丁寧に」で調整可 |

## 9. 海山に直接連絡したい時

- うみやまAI の使い方の根本疑問 → 海山に直接 LINE Works DM
- 機密に関わる懸念 → 海山に直接
- バグ・障害報告 → 海山に直接 (= 緊急なら LINE)
- 機能リクエスト → 海山に直接 or うみやまAI に「こういう機能欲しい」と言うと記録される

## 10. ベータ → v1 正式版になった変更点 (★2026-05-21)

| | ベータ (4 月-) | v1 (5 月 21 日-) |
|---|---|---|
| 応答モデル | fast-gpt (GPT-5.4-mini) | **smart (Claude Opus 4.8)** |
| 個別メモリー | なし | **有 (役職/所属/話題を蓄積)** |
| 会話一区切り後の整理 | なし | **有 (30 秒 idle で memory 再整理)** |
| 売上データ | 今日のみ | **3 年履歴 + 日次・月次・店舗別** |
| 議事録参照 | なし | **Plaud/Recall 議事録を参照可** |
| 添付ファイル対応 | なし | **PDF/Excel/Word/画像 OK** |
| URL 取り込み | なし | **メッセージ内 URL を自動 fetch** |
| 修正希望のフィードバック | あり (手動) | **直接返信「違う」「正しくは」で自動記録** |
| 応答品質チェック | なし | **毎晩 自動 regression test** |
| Hallucination 検出 | なし | **毎晩 post-hoc fact verifier** |

## 付録: 海山が裏で見てるダッシュボード

参考までに、海山は毎週以下を見て改善している:

- 全社員の利用統計 (どんな質問が多いか、応答時間、失敗率)
- 修正希望キュー (社員からの「違う」訂正)
- 会話発見 (= AI が「これ wiki に追加した方がいい」と判断した発見)
- ハルシネーション検出 (= AI が事実と違うことを言った場合)
- 月次 第三者評価 (= 5 名のレビュアーに blind 採点してもらってる)

これらを使って毎週 wiki / 応答スタイルを改善している。
